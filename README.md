## Project Scope

The objective of this project is to design and develop a responsive static portfolio website using HTML, CSS and JavaScript and understand the concepts involved in static website hosting and cloud deployment.

The project demonstrates the structure of a static website, frontend development, version control using GitHub, and deployment of the website as a live web application.

---

## Project Description

This project is a personal portfolio website created as part of the internship program.

The website contains multiple pages that present personal information, technical skills, projects and contact details.
